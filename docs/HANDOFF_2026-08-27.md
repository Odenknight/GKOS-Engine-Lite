## Current user-facing capability

See [CURRENT_CAPABILITIES.md](CURRENT_CAPABILITIES.md). The active branch
supports six restricted delegated commands—`validate`, `index`, `assess`,
`search`, `graph`, and `export graphiti`—plus the separate optional
proposal-only `assist` surface.

The command boundary is source-note preserving. `index` writes only governed
derived state through Full; graph/export write only explicitly requested output
files. No command automatically rewrites notes, lowers sensitivity, or grants
approval.
